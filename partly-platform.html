The protocol layer

A common protocol for an industry that's never had one.

Every participant in the parts industry speaks a different dialect. Partly translates between them — so insurers, OEMs, repairers, and dismantlers can finally work from the same data, in real time.

One protocol. Every participant.

Partly sits between the systems that already exist — translating part numbers, resolving fitment, surfacing inventory across networks. Build once, connect everywhere.

  • Standardised part IDs across every manufacturer and supplier catalogue.
  • Real-time supply visibility across dismantlers, distributors, and OEMs.
  • Webhooks and streaming for events that matter — orders, shipments, returns.
  • Regional compliance — NZ, AU, UK, EU, and US, with more coming.

Built for builders

An SDK, not a stack of integrations.

Type-safe SDKs in every major language. Resource-oriented endpoints. Webhook events. Pagination, retries, and idempotency that work the way you'd expect.

  • Single API for the entire workflow
    Identify, source, quote, order, track — every part operation through one consistent interface.
  • Type-safe SDKs
    JavaScript, Python, Ruby, Go, and Java. Auto-generated from OpenAPI, so the types match production.
  • Webhooks and streaming
    Subscribe to order events, supply changes, shipment updates. Push, not poll.
  • Bulk and batch operations
    Process millions of VINs or part lookups in a single job. Asynchronous, with progress callbacks.
  • Regional data residency
    NZ, AU, UK, EU, US. SOC 2 Type II, ISO 27001, GDPR compliant.
